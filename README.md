# Atlas for Rhythia

A desktop app for your Rhythia maps, scores and collections: your library, the Rhythia catalog, collections in Atlas, on Rhythia and in the game, downloads and backups. By Shuriel. Not made by the Rhythia team.

**Alpha.** Atlas works, but it is an early version with rough edges.

Download the installer (`Atlas.for.Rhythia_…_x64-setup.exe`) from [Releases](https://github.com/Shurielx/Atlas-For-Rhythia/releases). Windows only. Atlas updates itself.

## Building

Needs Node.js and Rust.

```
npm install
npm run dev      # run it
npm test         # tests
npm run build    # installer
```
