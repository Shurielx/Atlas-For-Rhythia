# Changelog

Each version: `## version · title · YYYY-MM-DD` (the next one: `## Next · title`), then `### Added`, `### Changed` or `### Fixed`, each change as `- Title: what changed`. After a change, run `npm run terms`.

## 0.13.10 · Changelog · 2026-11-27

### Added

- Changelog: Settings has a Changelog with every version since the first public one.

### Changed

- Names: "Save to Rhythia" is now "Copy to rhythia.com", and "Show in game" is now "Copy to game".
- Picking maps: The box at the top of a list ticks the whole page at once.
- Rhythia collections: Adding maps or removing them names the collection while it works.
- Types: The type legend under collections lines up, and Quantum has its own mark.

### Fixed

- Create: Create with no name now tells you to give the collection one.

## 0.13.9 · Sign-in window · 2026-11-26

### Fixed

- Sign-in window: The Rhythia sign-in window no longer stays empty for some players.
- Still empty: Atlas loads it again, and Settings → Account offers Sign in with Reimagined.

## 0.13.8 · Try at · 2026-11-23

### Changed

- Try at: Counts all your tries of a map in the game, not only your passes, so it suggests speeds you are likely to pass.

## 0.13.7 · RP gain · 2026-11-23

### Changed

- Worth another go: Gain shows how much your Rhythia RP would grow, not the map's RP.

### Fixed

- Worth another go: The table fits smaller windows.

## 0.13.6 · Map types · 2026-11-23

### Added

- Type filter: Catalog → All maps and Library can show only one type: Jump, Stream, Tech, Varied or Quantum.
- Worth another go: Can be sorted, and has a Gain column.

## 0.13.5 · First public alpha · 2026-11-23

### Added

- Atlas: The first public alpha.
- Uninstall: Settings → Data can uninstall Atlas, with or without your Atlas data.

### Changed

- Account: Settings → Account shows plainly whether you are signed in to Rhythia and whether Reimagined is connected.
